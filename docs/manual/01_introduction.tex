\section{Introduction}

\subsection{Abstract}
Welcome to the \textbf{Drone ERP User Manual} for Wingspann Global Pvt Ltd. This document provides a comprehensive operational guide for managing day-to-day operations using our customized Odoo Enterprise Resource Planning (ERP) platform. This manual covers detailed, step-by-step instructions for utilizing the system to handle Procurement, Inventory Management, and System Administration.

\subsection{System Overview}
The Drone ERP system integrates multiple facets of our operations into a single cohesive platform. 

\begin{figure}[H]
    \centering
    \includegraphics[width=0.9\textwidth]{images/dashboard.png}
    \caption{Odoo Main Dashboard (Home Menu)}
\end{figure}

The Main Dashboard provides direct access to the core modules:
\begin{itemize}[noitemsep]
    \item \textbf{Purchase:} For managing Request for Quotations (RFQs) and formal Purchase Orders (POs).
    \item \textbf{Inventory:} For tracking stock levels, processing internal transfers, and managing Issue Notes.
    \item \textbf{Settings:} For system administration and configuration.
\end{itemize}

\begin{notebox}
    To access the main dashboard at any time, click the \textbf{App Switcher} icon located in the top-left corner of the navigation bar.
\end{notebox}
